## 💘 Loventure

> **커플의 순간을 더 쉽고 즐겁게.**  
> 취향과 상황에 맞춰 데이트 코스를 추천하고, 추억을 다이어리로 저장하는 웹 서비스입니다.

## Service Key Features

- **코스 추천**: 두 사람의 취향·지역·시간·분위기·예산 기반으로 코스 카드 추천 
- **코스 관리**: 장소(POI) 묶음, 평점, 태그 관리 및 이력 저장후 
- **지역락 기능**: PostGIS로 반경/폴리곤 내 장소 조회 및 “지역 해금” 로직 처리
- **유저 관리**: Auth, User table 관리 및 인증 인가
- **다이어리 기능**: 다녀온 코스에대한 다이어리 작성 및 데이터 관리
